# chrono-identifiers

供运行代码和 Verus 证明共同使用的标识符校验。

运行 `VERUS=/path/to/verus ./check.sh` 构建并测试此库，执行生产和测试中的全部 Verus 证明。工具版本见 `rust-toolchain.toml` 与检查脚本。编译和验证产物在本次命令结束时清理。Cargo 使用方可按仓库 URL 和固定提交引用 `chrono-identifiers`。

源码和测试取自 [ChronoAIProject/chrono-harness 的固定提交](https://github.com/ChronoAIProject/chrono-harness/tree/7e99515590402f83c6b0931d8e37242dc32faf0d/crates/identifiers)。
